# Piggy

Piggy 是一个面向 Windows 的轻量中英互译桌面工具，翻译能力由用户自己的 DeepSeek API 提供。

## 当前版本（0.3.0）

- 配置并安全保存 DeepSeek API Key
- 测试 DeepSeek 连接
- 从下拉菜单选择普通翻译或深度翻译模型
- 为单词和短语显示音标、词性、常见释义及双语例句
- 自动识别中文或英文并进行中英互译
- 复制译文
- 在网页、Word、PDF 等软件中选中中文或英文并按自定义快捷键取词
- 可选择先显示小猪浮标，或按快捷键后直接显示解释
- 拖动透明背景的小猪浮标改变位置
- 点击浮标后在独立卡片中自动翻译
- 从主界面或翻译卡片收藏到本地生词本
- 生词本默认每条只占一行，点击后展开完整解释
- 备注和标签默认收起，需要时再编辑
- 搜索和删除生词；自动保留最近 100 条去重翻译历史
- 关闭主窗口后驻留系统托盘
- 从设置中开关浮标并调整停留时间
- 从设置中选择全局取词快捷键
- 为生词添加最多 500 字的本地备注
- 导入或导出生词本、备注和翻译历史（不包含 API Key）
- 安装版支持开机后台启动
- 对常见网络与 API 错误给出中文提示

## 本地开发

```powershell
npm.cmd install
npm.cmd run dev
```

类型检查与生产构建：

```powershell
npm.cmd run build
npm.cmd run smoke
```

## 使用划词浮标

保持 Piggy 运行，在网页、Word、PDF 或其他软件中选中中文或英文并按设置中的取词快捷键。默认点击鼠标旁出现的小猪即可打开 DeepSeek 翻译卡片；也可以在设置中开启“按快捷键后直接显示解释”。按住小猪拖动可以改变浮标位置。Piggy 优先使用 Windows UI Automation；不支持时会在后台临时读取选区并恢复原剪贴板内容。

当前请求模型可以在设置页的“DeepSeek 模型”中选择。默认值是 `deepseek-chat`，每次翻译结果下方也会显示 API 响应中的模型名称。

关闭主窗口后 Piggy 会留在 Windows 系统托盘。可以从托盘重新打开、临时暂停划词翻译或彻底退出。

生词本和最近 100 条翻译历史保存在当前 Windows 用户的 Piggy 本地数据目录中，不会同步到云端。

## Windows 安装包

生成安装程序：

```powershell
npm.cmd run dist:win
```

安装包会输出到 `dist` 文件夹。安装后可以在设置中开启“开机自动启动 Piggy”。
